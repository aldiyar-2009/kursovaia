# Две редакции: университет (LMS) и колледж (SmartNation)

Дата: 2026-11-02. Источник функций колледжа — проект `cursach akosi/cursach`
(`studyplan-server` + `studyplan_app`).

## Зачем

Приложением пользуются студенты университета (AITU, LMS Moodle) и студенты
колледжа (портал SmartNation, college.smartnation.kz). При входе человек
выбирает, кто он, и дальше получает свой набор функций и своё оформление.

## Решения пользователя

- На первом экране выбор: «Студент университета» / «Студент колледжа».
  Затем вход по своему логину и паролю или демо-режим.
- Колледж: всё из `cursach` — оценки SmartNation (темы занятий, средний балл,
  пропуски, предметы под угрозой), задания колледжа со статусами, расписание
  группы из Excel (пары, звонки, две смены), события из Telegram-канала,
  домашка группы и материалы, обмен своим расписанием в JSON — плюс основные
  функции StudyPlan (главная, задачи, группа, объявления). LMS нет.
- Университет: все функции StudyPlan (LMS-импорт, кредиты, what-if, карта
  кампуса, календарь), плюс события и обмен расписанием, плюс новая
  **аналитика оценок**. SmartNation нет.
- Пароль: у каждой редакции свой способ. Колледж — ИИН/логин и пароль
  SmartNation отправляются на наш сервер, он хранит их зашифрованными
  (AES-256-GCM) и сам обновляет оценки. Университет — как раньше, LMS через
  встроенный браузер, пароль на сервер не идёт.
- Чата нет ни в одной редакции. «Домашка группы» колледжа = существующие
  групповые задачи StudyPlan (`tasks.is_group`).
- Дизайн у обеих редакций — текущий дизайн StudyPlan (`kursovaia`):
  отличаются набор функций и экраны, а не оформление.

## Мои решения (можно поправить)

- Редакция хранится в `users.edition` (`university` | `college`) и локально в
  `AppSettings.edition`; гостевой режим остаётся (ссылка «Без аккаунта»).
- Навигация — 5 вкладок в обеих редакциях (Главная, Расписание, Задачи,
  Оценки, Ещё). События — блок на Главной + экран в «Ещё».
- Расписание группы колледжа импортируется в обычные `subjects`/`lessons`
  с детерминированными UUID (v5 от user + пары), поэтому работает везде:
  Главная, уведомления, экспорт ICS, синхронизация. Повторный импорт
  обновляет, исчезнувшие пары помечаются удалёнными.
- Снимок SmartNation кэшируется в SharedPreferences (`college.snapshot`).
- Источник событий — `EVENT_SOURCES` (по умолчанию `DSVR_News`), один для
  обеих редакций; обновление раз в 30 минут (setInterval, в тестах выключено).
- Ошибка `cursach`: в `parseSnDay` регулярное выражение без `\d` —
  исправлено при переносе.

## Контракт API (новое)

- `POST /api/auth/smartnation` `{login, password}` → `{token, user, group}`;
  `user.edition = 'college'`, `user.sn_group`. 400 пустые поля,
  401 `SN_INVALID_CREDENTIALS`, 502 `SN_UNAVAILABLE`. Группа с
  `groups.sn_group_name = sn_group` создаётся автоматически, пользователь
  вступает, если ещё не в группе. Ограничение частоты.
- `POST /api/auth/demo` `{edition?}` — для `college` демо-пользователь с
  `sn_group`, готовым снимком в `sn_snapshots` и примерами задач.
- `GET /api/college/snapshot`, `POST /api/college/refresh` (не чаще 60 с) →
  `{snapshot}`; 403 `NOT_COLLEGE` для других.
- `GET /api/timetable?group=` (публичный) → `{group, lessons:[{day_of_week,
  pair_no, start_time, end_time, subject, teacher, room, valid_from,
  valid_to}]}`; `GET /api/timetable/groups` → `{groups:[...]}`.
- `GET /api/events?scope=upcoming|past&limit=` (публичный) → `{events:[{id,
  title, text, starts_at (epoch ms), has_time, place, link, image_url,
  post_url}]}`.
- `normalizeUser` никогда не отдаёт `sn_credentials_enc`.

Форма снимка — как в `cursach` (`profile`, `subjects[].grades`, `stats`,
`assignments`).
