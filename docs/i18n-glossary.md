# StudyPlan — глоссарий локализации (ru → en / kk)

Цель: единая, проверенная терминология для перевода UI StudyPlan (Astana IT University) на английский и казахский (кириллица, современная литературная норма). Перед переводом любой строки сверяйтесь с этой таблицей; новые термины добавляйте сюда.

Дата исследования: 2026-10-26.

## Kazakh style rules for this app

1. **Обращение — «Сіз».** Все тексты, которые обращаются к пользователю, пишутся в вежливой форме: «қосыңыз», «Сіз әлі ... қосылмағансыз», «келе ме?». Обоснование: eGov.kz («алыңыз»), Kolesa («сканерлеңіз»), Microsoft (MS-SG весь в Сіз-форме) и университетские порталы используют только «Сіз»; «сен» в казахском UI воспринимается как фамильярность, особенно в вузовском приложении, где пользователь — взрослый студент. Местоимение «Сіз» явно пишем только когда без него неясно; обычно достаточно личного окончания (MS-SG: «не переводите каждое you»). «Пайдаланушы» вместо «вы» не использовать (MS-SG).
2. **Кнопки, пункты меню, команды — инфинитив (отглагольное имя на -у/-ю):** «Сақтау», «Бас тарту», «Жою», «Қосу», «Кіру», «Тіркелу», «Импорттау». Так делают Microsoft (MS-SG: «Command names should be translated as verbs ... always in the infinitive»), Kolesa («Хабарландыру беру», «Қосымшаны жүктеу»), Kaspi («Төлеу»), eGov («Кіру»). Императив «-ңыз/-ңіз» («Сақтаңыз») — только в поясняющих текстах, подсказках и empty-state («Тапсырманы қосыңыз»). «Өтінеміз» (please) не писать вообще (MS-SG); «Пожалуйста, подождите» → «Күте тұрыңыз».
3. **Процессы** — форма на «-уда/-уде»: «Жүктелуде…», «Синхрондалуда…». **Результат** — прошедшее время: «Сақталды», «Көшірілді», «Тапсырылды».
4. **Ошибки** — без восклицательных знаков, без обвинения пользователя (пассив): «Синхрондау мүмкін болмады», «Құпиясөз дұрыс емес». Шаблоны MS-SG: «... мүмкін емес», «... мүмкін болмады», «... кезінде қате пайда болды», «... жоюға сенімдісіз бе?».
5. **Числа и мн. число.** После числительного существительное в единственном числе: «5 кредит», «3 тапсырма», «2 сабақ», «12 мүше». Также после «барлық», «бірнеше», «көп»: «бірнеше тапсырма». В строках с плейсхолдерами (`{count}`) это упрощает ICU — для kk достаточно формы `other`; ru требует `one/few/many`. Если число стоит в конце, используйте конструкцию «Тапсырмалар: {count}» (MS-SG: «Анықталған қалталар: %1»). Порядковые — цифра + дефис: «5-апта», «2-межелік бақылау», «3-курс».
6. **Аббревиатуры** (GPA, LMS, ECTS, Microsoft): окончания к латинице не присоединять; ставить слово-дескриптор: «LMS жүйесінен», «GPA мәні» (MS-SG).
7. **Даты и время.** 24-часовой формат «08:30». Числовая дата «26.10.2026». Короткая — «26 қазан», с днём недели — «Дүйсенбі, 26 қазан». Полная — «2026 жылғы 26 қазан» (официальная) или «2026 ж. 26 қазан» (CLDR kk, его выдаёт `intl` / `DateFormat.yMMMd('kk')`). Названия месяцев и дней недели — со строчной буквы внутри предложения: «қазан», «сейсенбі» (MS-SG); с заглавной только в начале строки или заголовка. Месяцы: қаңтар, ақпан, наурыз, сәуір, мамыр, маусым, шілде, тамыз, қыркүйек, қазан, қараша, желтоқсан. Дни: дүйсенбі, сейсенбі, сәрсенбі, бейсенбі, жұма, сенбі, жексенбі. Сокращения: Дс, Сс, Ср, Бс, Жм, Сб, Жс.
8. **Заглавные буквы** — sentence case: заглавная только у первого слова («Кампус картасы», «Профиль және параметрлер», не «Кампус Картасы»). Языки и национальности со строчной: «қазақ тілі», «ағылшын тілі». В переключателе языков названия пишутся самоназванием: «Қазақша», «Русский», «English».
9. **Лексика.** Избегать канцеляризмов («қазіргі таңда» → «қазір», «... мақсатында» → «... үшін»), по MS-SG. «Қосымша» = приложение (app), «тіркелгі» / «аккаунт» = учётная запись (выбрать «аккаунт» для своего приложения, «тіркелгі» — для Microsoft, как в оригинальной Microsoft-локализации), «құпиясөз» — одним словом.
10. **Английский** — естественный продуктовый английский в sentence case: «Sign in», «Due date», «Retake», «Admission rating», «Increased scholarship», «Group leader». Названия контрольных AITU оставлять как в LMS: «Midterm», «Endterm», «Final».
