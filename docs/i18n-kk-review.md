# Казахский перевод UI: независимая ревизия

Файлы: `mobile/lib/l10n/app_kk.arb`, сверка с `app_ru.arb` (источник) и `app_en.arb` (для уточнения смысла). Ревизия проводилась по временным частям `l10n/parts/`, позже слитым в эти три файла.
Опора: `docs/i18n-glossary.md` (термины + «Kazakh style rules»), MS Kazakh Style Guide, академические политики казахстанских вузов (ZHU, IUTH, KEU — ссылки в глоссарии).
Этот документ заменяет списки сомнений переводчиков `i18n-kk-review-a.md` и `i18n-kk-review-b.md`, их содержимое учтено ниже.

## Итог

- Проверены все ~330 строк kk. **Изменено 23 строки**, удалено 8 неиспользуемых ключей (`nav_homeTitle`, `nav_homeEmptyTitle`, `nav_homeEmptyMessage`, `nav_homeEmptyAction`, `nav_groupEmptyTitle`, `nav_groupEmptyMessage`, `common_loading`, `lms_unsupported`), их уже нет в ru-источниках ветки `redesign`.
- Перевод в целом грамотный: Сіз-обращение выдержано, кнопки стоят в инфинитиве, «Бас тарту» = Cancel, окончания к латинице (LMS, GPA) не присоединяются, ICU-плюралы корректны (`other` для kk), плейсхолдеры совпадают с ru во всех строках (проверено скриптом).
- Ошибки в основном двух видов: один и тот же термин переведён по-разному в разных файлах, и подписи для узких мест получились длиннее русских.

## Нужна проверка носителем из AITU (студент или сотрудник)

1. **«Рейтинг допуска»** → «Жіберу рейтингі» (кратко «рейтинг»). В разных вузах встречаются «рұқсат рейтингі», «емтиханға жіберілу рейтингі (ЖР)». Нужно уточнить, как говорят в AITU.
2. **«Отработка»** (`grades_statusFailed`) → «Қайта тапсыру». Если в AITU имеется в виду повторное прохождение дисциплины (retake, летний семестр), точнее «Қайта оқу».
3. **Чётная / нечётная неделя** → «Жұп / тақ апта». Математически корректно, но в официальных вузовских документах не найдено.
4. **Аббревиатура РК** → «МБ1…МБ4» в академическом календаре. Возможно, в AITU на казахском используют «АБ» или оставляют «РК / Midterm».
