# Полное описание проекта «StudyPlan»
## Кроссплатформенный студенческий органайзер с поддержкой офлайн-режима

---

## 1. Введение и концепция проекта

### 1.1. Проблема
Студенты современных вузов и колледжей ежедневно сталкиваются с фрагментацией учебной информации:
* Расписание занятий меняется (чётные/нечётные недели, переносы) и часто хранится в неудобных таблицах или PDF;
* Домашние задания, дедлайны по лабораторным и курсовым работам теряются в общих беседах мессенджеров;
* В аудиториях или цокольных этажах корпусов часто пропадает интернет, из-за чего веб-порталы вузов становятся недоступны;
* Старосте сложно централизованно оповещать одногруппников об изменениях в расписании и собирать подтверждения о сдаче домашних заданий.

### 1.2. Решение: StudyPlan
**StudyPlan** — это мобильное и десктопное приложение, построенное по архитектуре **Offline-First**. Приложение сохраняет всю базу данных локально на устройстве и фоново синхронизирует её с сервером при появлении сети.

**Ключевой девиз проекта:** *Никаких пустых белых экранов без интернета — расписание, задачи и файлы всегда под рукой.*

## 2. Архитектура и стек технологий

### 2.1. Клиентская часть (Mobile / Desktop)
* **Фреймворк:** Flutter (Dart 3.x), кроссплатформенная поддержка Windows, Android, Web.
* **Локальная база данных:** `drift` (типобезопасная ORM для SQLite) + `drift_flutter`.
* **Управление состоянием (State Management):** `BLoC` (`flutter_bloc`) для модуля синхронизации + реактивные потоки данных (`StreamBuilder`) для реактивного обновления интерфейса в реальном времени.
* **Сетевой слой:** `Dio` с интерцепторами авторизации (Bearer JWT).
* **Дизайн-система:** Авторская тема **Stealth Dark / Midnight Slate**:
  * Основной фон: `#0C0D11`
  * Поверхности карточек: `#15171E`
  * Поля ввода и кнопки: `#1E212B`
  * Границы и разделители: `#272A36`
  * Фирменные акценты: глубокий индиго `#6366F1` и яркий циан `#06B6D4`
  * Шрифтовая гарнитура: Inter / San Francisco.

### 2.2. Серверная часть (Backend API)
* **Среда выполнения:** Node.js (ESM).
* **Фреймворк:** Express.js.
* **Слой данных:** Knex.js Query Builder с автоматическими миграциями и сидами.
* **Базы данных:** SQLite (для локальной разработки и тестирования) с возможностью мгновенного переключения на PostgreSQL через `.env`.
* **Realtime-коммуникация:** `Socket.IO` для чата группы в реальном времени.
* **Аутентификация:** JSON Web Token (JWT) + хеширование паролей алгоритмом `bcrypt` (10 раундов соли).
* **Синхронизация:** Двунаправленный батч-протокол `POST /api/sync` по алгоритму **Last-Write-Wins (LWW)** на основе временных меток с поддержкой «мягкого удаления» (tombstone / `is_deleted`).

## 3. Подробный обзор модулей и функций

### Модуль 1. Экран-заставка (Splash Screen)
* **Файл:** `mobile/lib/features/splash/presentation/screens/splash_screen.dart`
* **Функционал:**
  * Отображение логотипа с градиентным свечением и пульсирующей анимацией (`CurvedAnimation`, `ScaleTransition`).
  * Проверка локального хранилища `SharedPreferences`:
    * Если есть действующий токен и данные пользователя $\rightarrow$ плавный переход на Главный экран (`MainShellScreen`).
    * Если сессии нет $\rightarrow$ переход на экран авторизации (`AuthScreen`).
  * Статус-текст хода инициализации («Инициализация модулей...», «Проверка сохраненной сессии...»).

### Модуль 2. Авторизация и регистрация (Auth & Registration)
* **Файл:** `mobile/lib/features/auth/presentation/screens/auth_screen.dart`
* **Функционал:**
  * **Регистрация:** Ввод ФИО, Email, Кода группы, Пароля и Подтверждения пароля. Полная валидация (непустые поля, RegEx email, пароль от 6 символов, проверка совпадения паролей).
  * **Вход:** Ввод почты и пароля, скрытие/показ символов пароля, вывод серверных ошибок.
  * **Демо-аккаунты:** Кнопки быстрого заполнения для защиты курсовой:
    * *Староста:* `headman@studyplan.dev` / `password123`
    * *Студент:* `student@studyplan.dev` / `password123`
  * Поддержка кодов приглашения (`IVT21A` для группы ИВТ-21).

### Модуль 3. Главная страница: Таймлайн дня (Timeline Screen)
* **Файл:** `mobile/lib/features/timeline/presentation/screens/timeline_screen.dart`
* **Функционал:**
  * Почасовая шкала занятий текущего дня.
  * Подсветка статуса пары: «Идёт сейчас» (акцентный индикатор), «Следующая», «Завершена».
  * Карточка занятия: предмет, преподаватель, аудитория/корпус, тип пары (Лекция / Практика / Лабораторная), цветовой бейдж дисциплины.
  * Интерактивность: нажатие на карточку открывает шторку для быстрого создания дедлайна или заметки по этому предмету.

### Модуль 4. Полное расписание (Schedule Screen)
* **Файл:** `mobile/lib/features/schedule/presentation/screens/schedule_screen.dart`
* **Функционал:**
  * Переключатель чётности недели: «Чётная неделя (Знаменатель)» и «Нечётная неделя (Числитель)».
  * Табы по дням недели (Понедельник — Суббота).
  * Возможность просмотра всего семестрового графика.
  * Клик по любой паре для добавления домашних заданий.

### Модуль 5. Дедлайны и задачи (Deadlines & Tasks)
* **Файлы:**
  * `mobile/lib/features/tasks/presentation/screens/deadlines_screen.dart`
  * `mobile/lib/features/tasks/presentation/widgets/task_detail_bottom_sheet.dart`
* **Функционал:**
  * **Быстрый инбокс (Quick Add):** Создание задачи в 1 нажатие клавиши Enter.
  * **Расширенная форма (TaskDetailBottomSheet):**
    * Выбор предмета из списка;
    * Дата и время сдачи (Date & Time Picker);
    * Приоритет (Низкий, Средний, Высокий, Срочно);
    * Чек-лист подзадач с прогрессом выполнения;
    * Прикрепление файлов (конспекты, методички, лабораторные);
    * Тумблер «Опубликовать для группы» (доступен старосте).
  * **Поиск:** Поиск по названию и описанию задач на лету.
  * **Фильтры:**
    * По статусу: «Все задачи», «В работе», «Выполненные»;
    * По предметам: цветные чипы дисциплин.
  * **Жесты:** Свайп вправо — переключение статуса задачи, свайп влево — удаление задачи.

### Модуль 6. Групповой хаб и чат старосты (Group Chat Hub)
* **Файл:** `mobile/lib/features/chat/presentation/screens/group_chat_screen.dart`
* **Функционал:**
  * Обмен текстовыми сообщениями в группе через WebSockets (`Socket.IO`).
  * Локальное кэширование переписки: чат доступен для чтения даже без интернета.
  * **Специальные карточки старосты:**
    * *«Домашнее задание» (Homework Card):* Интерактивная карточка с описанием и кнопкой «Добавить в мои дедлайны» для каждого студента.
    * *«Изменение в расписании» (Schedule Change Card):* Официальное уведомление об отмене или переносе пары.
  * Возможность закрепления сообщений (Pin message).

### Модуль 7. Интерактивная карта кампуса (Campus Map)
* **Файл:** `mobile/lib/features/campus_map/presentation/screens/campus_map_screen.dart`
* **Функционал:**
  * Карта кампуса университета (Astana IT University / EXPO, Астана).
  * Метки учебных блоков, коворкингов, библиотеки, столовой и деканата.
  * Интерактивный зум и детальная информация о корпусах.

### Модуль 8. Профиль пользователя (Profile Screen)
* **Файл:** `mobile/lib/features/profile/presentation/screens/profile_screen.dart`
* **Функционал:**
  * Крупный аватар с бейджем роли (Староста / Студент).
  * Информация об академической группе, семестре и инвайт-коде.
  * **Статистика успеваемости:** Подсчёт общего числа дедлайнов, задач в процессе, выполненных и процент успешности с прогресс-баром.
  * **Редактирование профиля:** Изменение имени пользователя в модальном режиме с сохранением на бэкенде (`PATCH /api/auth/me`).
  * **Безопасный выход:** Кнопка «Выйти из системы» с подтверждением и очисткой токена из `SharedPreferences`.

### Модуль 9. Движок синхронизации и резервного копирования
* **Файлы:**
  * `mobile/lib/core/sync/sync_repository.dart`
  * `mobile/lib/core/sync/sync_bloc.dart`
* **Функционал:**
  * Отслеживание сетевого статуса через цветной индикатор в AppBar (Зелёный — синхронизировано, Синий — синхронизация, Оранжевый — есть локальные изменения, Красный — офлайн).
  * Экспорт и импорт расписания в формат `schedule.json` для резервного копирования или обмена между группами.
